# 🏥 Sistem Informasi Manajemen Rumah Sakit (Native PHP)

Aplikasi web sistem informasi rumah sakit sederhana yang dibangun menggunakan **PHP Native** dan **MySQL**. Proyek ini dirancang untuk memudahkan pengelolaan data pasien serta administrasi dasar di lingkungan rumah sakit.

---

## ✨ Fitur Utama
* **Autentikasi (`login.php`)**: Sistem masuk yang aman bagi pengguna atau admin[cite: 1].
* **Manajemen Pasien (`pasien.php`, `tambahpasien.php`, `editpasien.php`)**: Fitur untuk melihat daftar pasien, menambahkan data pasien baru, serta memperbarui informasi pasien[cite: 1].
* **Manajemen Tim (`anggota.php`, `ketua.php`)**: Halaman khusus untuk menampilkan informasi struktur tim atau pengembang proyek[cite: 1].
* **Koneksi Database (`koneksi.php`)**: Berkas konfigurasi untuk menghubungkan aplikasi dengan database MySQL[cite: 1].

---

## 🛠️ Teknologi yang Digunakan
* **Bahasa Pemrograman:** PHP (Native)[cite: 1]
* **Database:** MySQL[cite: 1]
* **Frontend:** HTML, CSS, JavaScript
